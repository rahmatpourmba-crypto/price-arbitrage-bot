# ربات آربیتراژ ایران ↔ عراق/خلیج

ربات تلگرام برای پیدا کردن فروشندگان ارزان ایرانی و خریداران در کردستان عراق، کشورهای حوزه خلیج و شهرهای مختلف ایران.

## دستورات ربات

| دستور | توضیح |
|-------|--------|
| `/start` | نمایش راهنما |
| `/hot` | پرتقاضاترین کالاها + لینک خریداران |
| `/hot الکترونیک` | کالاهای یک دسته خاص |
| `/cheap <نام کالا>` | فروشندگان ارزان دیوار |
| `/buyers <نام کالا>` | خریداران تهران |
| `/regions <نام کالا>` | خریداران کردستان + خلیج + بین‌الملل |
| `/arb <نام کالا>` | تحلیل آربیتراژ |
| `/links <نام کالا>` | لینک‌های مستقیم به سایت‌ها |

## منابع اطلاعاتی

### اسکرپ مستقیم (داده واقعی)
- **دیوار** - فروشندگان و خریداران ایران

### لینک‌های مستقیم
- **کردستان عراق**: Haraj, Bazar1, Facebook Marketplace (اربیل، سلیمانیه، دهوک)
- **خلیج**: Dubizzle, Amazon AE, Haraj, OpenSooq (امارات، عربستان، کویت، قطر، بحرین، عمان)
- **بین‌المللی**: OLX Pakistan, OLX India, Alibaba, Amazon, eBay, AliExpress, Etsy
- **ایران**: دیوار (15 شهر)
